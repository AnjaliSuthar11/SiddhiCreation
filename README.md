# Crafted Creations Studio

WEBSITE REDESIGN PROMPT — SIDDHI ON CREATION

Redesign the website for Siddhi On Creation & Mrudula Creation into a highly premium, modern, visually stunning, and professional architectural art and custom creation website.

The current business has over 30+ years of experience in creating customised sculptures, murals, decorative gates and grills, CNC designs, MDF work, FRP products, outdoor furniture, planters, architectural decorative elements, and custom artistic installations.

The new website should feel like a premium architectural design studio and luxury art portfolio, not a basic corporate website.
